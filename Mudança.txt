NO TEU PC (desenvolvimento):
1. Fazer commit e push de tudo para o GitHub
   └── git add .
   └── git commit -m "Adicionar sync com Supabase"
   └── git push

NO PC DO PAI:
2. Instalar as dependências novas
   └── pip install supabase python-dotenv

3. Criar o ficheiro .env na raiz do projecto
   └── SUPABASE_URL=https://aacjetgkrxbprluscivm.supabase.co
   └── SUPABASE_KEY=a tua anon key

4. Correr a migração com a BD REAL
   └── python migrar_para_supabase.py
   └── Isto envia todos os dados reais para o Supabase

5. Fazer novo build
   └── python build.py
   └── Substituir o executável anterior pelo novo
