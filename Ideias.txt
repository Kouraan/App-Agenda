Ótima questão! Para um projeto de agenda moderno, usar ficheiros .json é uma escolha muito melhor do que ficheiros de texto simples ou ficheiros binários de objetos, porque:

JSON é legível, fácil de editar e de integrar com outras aplicações.
Existem bibliotecas Java que facilitam muito a leitura e escrita de objetos em JSON.
Como fazer o parse de .json em Java
1. Usar uma biblioteca JSON
As mais comuns são:

Jackson
Gson

Preciso de ficheiro binário?
Não!
Com JSON, não precisas de ficheiros binários nem de ObjectOutputStream.
JSON é mais flexível, portável e fácil de manter.

Resumo
Usa uma biblioteca como Gson ou Jackson.
Lê e escreve listas de objetos diretamente em ficheiros .json.
O parse é automático: a biblioteca converte entre JSON e os teus objetos Java.

COMO DAR JPACKAGE:

-Compilar as classes e passar para a pasta out
javac -d out -cp "lib/gson-2.10.1.jar:../javafx-sdk/lib/*" $(find src -name "*.java")
(no meio colocasses as bibliotecas utilizadas)

-Copiar os .fxml para a pasta out
cp src/view out/

-Criar o .jar executavel
jar --create --file AppAgenda.jar --main-class Main -C out .

-Testar se o jar esta funcional
java --module-path ../javafx-sdk/lib --add-modules javafx.controls,javafx.fxml \
     -cp "AppAgenda.jar:lib/gson-2.10.1.jar" Main

-Usar o JPACKAGE
jpackage \
  --name AppAgenda \
  --input dist \
  --main-jar AppAgenda.jar \
  --main-class Main \
  --type app-image \
  --java-options "--module-path ../javafx-sdk/lib --add-modules javafx.controls,javafx.fxml" \
  --app-version 1.0 \
  --vendor "Kouraan"

-Executar
./AppAgenda/bin/AppAgenda
